# Notes — Система управления заметками и категориями

Python-приложение для создания, хранения и управления заметками с категориями. Данные сериализуются и сохраняются в CSV-файлы.

## Архитектура

Проект построен на принципах ООП с использованием наследования, миксинов и обобщённых типов (generics):

```
models/        — Модели данных (Base, Entity, Category, Note)
storage/       — Слой хранения (CSVStorage, CategoryStorage, NoteStorage)
mixins/        — Миксины (Serializable)
main.py        — Точка входа и пример использования
settings.py    — Конфигурация (пути к файлам)
```

## Модели

| Модель     | Описание                                                       |
|------------|----------------------------------------------------------------|
| `Base`     | Базовый класс с уникальным идентификатором (UUID)              |
| `Entity`   | Сущность с именем (`name`) и описанием (`description`)         |
| `Category` | Категория заметок, наследуется от `Entity`                     |
| `Note`     | Заметка с заголовком (`title`) и текстом (`text`), привязана к категории |

## Хранение

- **CSVStorage** — универсальное абстрактное хранилище с сериализацией/десериализацией объектов в CSV и обратно
- **CategoryStorage** — специализированное хранилище для категорий с методами `create()`, `all()`, `get_by_name()`
- **NoteStorage** — хранилище заметок с возможностью фильтрации по категории через метод `get_by_category()`

## Возможности

- ✅ Создание категорий и заметок
- ✅ Автоматическая генерация уникальных идентификаторов (UUID)
- ✅ Сохранение и загрузка данных из CSV-файлов
- ✅ Фильтрация заметок по категориям
- ✅ Сериализация/десериализация объектов через миксин `Serializable`
- ✅ Типизация с поддержкой обобщённых типов (Generics)

## Зависимости

Проект использует только стандартную библиотеку Python. Дополнительные пакеты не требуются.


## Установка и запуск

Проект не требует установки сторонних пакетов — используется только стандартная библиотека Python 3.11+.

### Быстрый старт

```bash
# 1. Перейдите в директорию проекта
cd notes

# 2. Запустите проект
python main.py
```

### Как работает main.py

При запуске `main.py` выполняет следующие шаги:

1. **Проверка категорий** — если хранилище категорий пусто, создаются три категории по умолчанию:
   - **Дом** — всё, связанное с делами по дому
   - **Работа** — всё, связанное с делами по работе
   - **Семья** — всё, связанное с делами с семьёй

2. **Проверка заметок** — если хранилище заметок пусто, создаются примеры заметок:
   - **Крыльцо** (Дом) — расчёт стоимости крыльца
   - **Python** (Работа) — задача по доработке AI-агентов
   - **Сын** (Семья) — поиск школ карате по району

3. **Вывод данных** — отображает все категории с привязанными к ним заметками в формате:
   ```
   Дом Крыльцо
   - первый этап расчеты
   ```

## Структура данных

Данные хранятся в директории `data/`:
- `data/categories.csv` — категории
- `data/notes.csv` — заметки
