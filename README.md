# Notes — Система управления заметками и категориями

Python-библиотека для создания, хранения и управления заметками с категориями. Данные сериализуются и сохраняются в CSV-файлы.

## Архитектура

Проект построен на принципах ООП с использованием наследования, миксинов и протоколов:

```
models/        — Модели данных (Entity, Category, Note)
storage/       — Слой хранения (CSVStorage, CategoryStorage)
mixins/        — Миксины (Serializable)
main.py        — Точка входа и примеры использования
settings.py    — Конфигурация (пути к файлам)
```

## Модели

| Модель      | Описание                          |
|-------------|-----------------------------------|
| `Base`      | Базовый класс с идентификатором (UUID) |
| `Entity`    | Сущность с именем и описанием     |
| `Category`  | Категория заметок                 |
| `Note`      | Заметка с заголовком и текстом, привязанная к категории |

## Хранение

- **CSVStorage** — универсальное хранилище с сериализацией/десериализацией в CSV
- **CategoryStorage** — специализированное хранилище для категорий с методами `create()`, `all()`, `get_by_name()`

## Зависимости

Только стандартная библиотека Python:
- `uuid`, `pathlib`, `csv`, `typing`

## Установка и запуск

Проект не требует установки сторонних пакетов — используется только стандартная библиотека Python 3.11+.

### Быстрый старт

```bash
# 1. Перейдите в директорию проекта
cd notes

# 2. Запустите проект
python main.py
```

### Запуск тестовых примеров

В `main.py` определены три функции-демонстрации:

```python
# Создать и прочитать категорию
demo_create_and_read()

# Пример работы с CategoryStorage
example_category_storege()

# Основной пример (создание категории + заметки)
main()
```

Для запуска конкретной функции раскомментируйте нужную в блоке `if __name__ == '__main__':`.

## Структура данных

Данные хранятся в директории `data/`:
- `data/categories.csv` — категории
- `data/products.csv` — заметки
